## 0.0.33

### 新功能

- **文件树全套文件操作**：右键菜单（七个新图标：新建文件/文件夹、复制、剪贴、重命名、删除等，按目录 / 文件 / 空白区三种上下文接线）+ 拖拽移动（同名自动重命名，目标在源之下等危险移动直接拒绝）+ 快捷键 `F2` 重命名 / `Delete` 删除 / `Esc` 取消，`+` 新建按钮跟随当前选中项（选中目录在目录下建、选中文件在同级建）。配套主进程 `copyEntries` 复制/移动与剪贴板路径 IPC。
- **文件树内部剪贴板与粘贴**：`Ctrl+C` / `Ctrl+X` / `Ctrl+V` 走会话内剪贴板，粘贴入口在右键菜单**始终渲染**，三级回退（内部剪贴板 → 系统剪贴板文件路径 → 空则提示「剪贴板为空」），系统剪贴板里来自资源管理器的文件也能粘进来。
- **定时任务运行流水重设计**：改时间轴五色节点版式，tool / 思考 / 诊断条目默认折叠、正文 Markdown 渲染且永不折叠；出场节奏由播放队列统一控制（正文打字机、行滑入、积压超过 5 条自动快进），状态呼吸点与滑入动画均带 reduced-motion 豁免（系统关闭动画时照常播放）。自动触发的运行会自动跟随打开详情，滚动跟随修正在封高的滚动容器上。
- **会话右栏重构为 RightWorkspacePane**：收起后顶部行完全隐藏、右缘只留一个展开图标（展开请求 500ms 防抖，杜绝「点收起像没反应再点一次」被翻回），收起态终端脱流铺满整个内容区；文件树折叠状态按会话记忆 —— 首次进入默认展开，之后以该会话上一次状态为准，新会话不继承残留。`FileTabs` 上移到右栏顶部行，多 tab 不再把收起按钮挤出视口。

### 修复

- **文件树外部删除后选中态不再指向幽灵路径**：工作区文件在外部被删除时，watcher 刷新树后同步清空已不存在的选中项，避免此时按 `+` / `F2` / `Delete` 操作一个已经不存在的路径。
- **Windows 剪贴板路径 FileNameW 反斜杠归一化**：`buildFileNameW` 编码前把正斜杠归一为反斜杠（`CF_HDROP` 惯例），修复混合斜杠路径粘贴丢文件的问题。
- **定时任务详情两处失联修复**：自动触发的 run 不刷新详情（`runChanged` 在未钉住历史时自动跟随打开）、滚动跟随失效（滚动条实际在封高的 `.sbody` 上，原先 `scrollTo` / `onScroll` 挂在外层空转）。

### 说明

- **Claude 启动探测改 fire-and-forget**：`claude --version` 探测原先串行等待在 PTY spawn 之前，主进程上下文实测 3~8s+，每次开会话都要白付这笔延迟；改为后台执行、失败只记日志，真正的启动失败仍由 spawn 异常与退出诊断兜底展示。实测开会话快约 2s（首次 8s→6s）。
- **移除行内 blame 与编辑器独立字号**：行内 blame 渲染层整套下线（FileTabs 开关、行尾注解、IPC 封装，`git blame` 主进程能力与测试保留）；`code.fontSize` 设置项删除，编辑器字号统一跟随终端字号。
